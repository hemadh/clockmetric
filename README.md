# ClockMetric

ClockMetric is an employee time-tracking and workforce management application.

It allows businesses to manage employees, projects, working hours, screenshots, activity, leave and reports from one workspace.

## Main Users

### Admin
The Admin manages:
- Employees
- Projects
- Timesheets
- Screenshots
- Keyboard activity
- Leave
- Reports
- Workspace settings
- Subscription and billing

### Employee
Employees can:
- View assigned projects
- Start and stop their timer
- Record working hours
- View their timesheet
- View permitted activity information

## Technology

- Flutter
- Dart
- Supabase
- Windows Desktop
- Web access for administrators
